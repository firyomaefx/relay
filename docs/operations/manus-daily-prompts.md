# Manus daily prompts (≈300 credits)

Manus does not integrate with Relay. Use these prompts to spend credits on copy Relay ingests via console, Email library, or MCP.

## 1. Threads + promo week (≈80–120 credits)

> Research Malaysian SMB creators using Threads for product tips. Return a table: audience pain, 5 hook lines, 3 CTA variants. Draft one 280-character Threads post and one Brevo promo email (subject + HTML body with one CTA to relay.duitpoket.fun). Tone: helpful, not hype.

**Relay:** paste email HTML into Email → Library; schedule via Email tab or `relay_post` for Threads.

## 2. Inbound reply tone guide (≈40 credits)

> Write a short style guide for auto-replying to Threads comments on scheduling/publishing tools: when to reply, when to ignore spam, max length, no hashtags, English with optional one Malay phrase. Include 5 example comment → reply pairs.

**Relay:** customers add DeepSeek key; guide informs library promo template footers.

## 3. Waitlist landing variants (≈60 credits)

> Propose three waitlist page headlines + subheads for “Relay Cloud — schedule X/Threads without babysitting the browser.” Include one FAQ block objecting to price; answer with prepaid top-up model.

**Relay:** update `apps/web` marketing copy manually when a variant wins.

## Credit discipline

- Batch outputs weekly; avoid re-researching the same niche daily.
- Relay handles publish, webhooks, billing, and sleep mode 24/7 — Manus does not replace operator deploy or `verify-sleep-mode`.
