Quickstart

Connect your AI agent to Relay Cloud over MCP and send your first post.

1. Get your API key

Join the waitlist. When you're approved, you get a private connection link by email. It shows your Relay API key once. The key starts with rly_. Keep it secret, it works like a password.

2. Add Relay to your MCP client

Relay Cloud speaks Streamable HTTP MCP at this URL:

https://cloud-mcp.duitpoket.fun/mcp

Send your key in the Authorization header. For Cursor, Claude Desktop and most clients that read a JSON config:

{
  "mcpServers": {
    "relay-cloud": {
      "url": "https://cloud-mcp.duitpoket.fun/mcp",
      "headers": { "Authorization": "Bearer rly_your_key_here" }
    }
  }
}

For Claude Code:

claude mcp add --transport http relay-cloud https://cloud-mcp.duitpoket.fun/mcp \
  --header "Authorization: Bearer rly_your_key_here"

Opening the MCP URL in a browser returns 401. That's expected, it only answers MCP clients with a key. The connection guide has configs for more clients.

3. Connect your social accounts

Ask your agent to run relay_accounts to see what's connected, then relay_connect with a platform name (x, threads, tiktok, youtube, instagram or linkedin). It returns a link you open to approve access on that platform.

4. Your first post

You can just tell your agent: "Post this to Threads and LinkedIn tomorrow at 9am Malaysia time." Under the hood it validates first, then posts or schedules. The tool calls look like this:

relay_validate
{
  "platforms": ["threads", "linkedin"],
  "text": "Hello from my agent. First post through Relay."
}

relay_post
{
  "platforms": ["threads", "linkedin"],
  "text": "Hello from my agent. First post through Relay.",
  "schedule_at": "2026-12-01T09:00:00+08:00"
}

Leave out schedule_at to post right away. Use relay_queue to see scheduled posts and relay_cancel to cancel one before it runs. Cancelling releases the held amount.

Limits

Relay checks these before anything is published. If text is longer than a platform's per-part limit, Relay auto-threads it into extra parts and charges $0.02 per text part ($0.04 for two, $0.06 for three) instead of rejecting the draft. A platform that only supports one part cannot auto-thread past its own limit.

  • YouTube titles are limited to 100 characters.
  • Threads, Instagram and TikTok photo posts fetch media from a public URL, so media you upload to Relay is served from a public link.
  • Rate limits per customer: 120 MCP requests per minute and 60 posts per hour.
  • Your agent can call relay_limits for the current limits at any time.

Billing

Relay is prepaid. Each post part on each platform is priced in advance, held when you post or schedule, and charged only when the platform accepts it. See pricing for rates, and top up by card when you need more credit.
