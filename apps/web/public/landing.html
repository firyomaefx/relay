How it works

Three steps, no setup maze.

1. Connect an account

Sign in once for each platform you use. Start with one and add the rest later.

2. Write once

Add text, photos or video. Check the preview for each network before you post.

3. Post or schedule

Publish now or pick a time. Cancel anything still waiting, and retry only the platforms that failed.
