About Relay Cloud

A publishing layer built for the agent era.

Relay Cloud gives small teams and AI agents one controlled path from draft to six social platforms. It is live in production, not a concept deck.

What we build

One MCP endpoint and HTTP API for X, Threads, TikTok, YouTube, Instagram and LinkedIn. Your agent validates a draft, publishes or schedules it, and Relay handles platform rules, retries and billing.

Where we are

Live in production on Google Cloud. Six platform adapters, a cloud MCP server, a customer console, Stripe and Polar checkout, and a prepaid usage ledger. The public docs and pricing are live.

How we work

Founder-led and deliberately small. We ship in production, measure what works, and keep the scope narrow: reliable publishing through agents, with a human approval path when the work needs one.
