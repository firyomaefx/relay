Your API key is the password. It is shown once when your Relay customer is provisioned. Do not put it in a public URL or commit it. The /mcp URL is an API endpoint; opening it in a browser returns 401 by design. Use /health for a browser check.
1. Get provisionedA Relay operator creates your customer account and API key. No public self-signup yet.
2. ConnectAdd the endpoint in your MCP client using the API key or OAuth.
3. VerifyCall relay_balance or relay_accounts to confirm the connection and see your state.
